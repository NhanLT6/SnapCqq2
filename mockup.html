—
Tab name recommendation: "General" — it's the most familiar term for app-wide settings (used by VS Code, Chrome, Windows itself). Alternatives:
  • System — emphasises Windows-level integration (startup, tray), but feels more technical
  • App Settings — very explicit, but a bit long for a tab label

Key decisions in this mockup:
  • WHEN card is always expanded (it's the primary config you touch daily)
  • HOW and AFTER cards start collapsed — click header to expand
  • Enable / Disable button lives in the status bar (right side), replacing the big button
  • Manual tab uses the same card structure: RUN card (always open) + HOW card (collapsible)
  • General tab adds "Start minimized" and "Default mode" as bonus settings that belong there
